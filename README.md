# GraphQL Users API

A simple GraphQL CRUD API for managing users, built with Node.js, Express, and Apollo Server.

> 🚀 Great for beginners learning GraphQL and Apollo Server with Node.js.

---

## 📦 Features

- 🔍 Query all users
- ➕ Add a user
- 📝 Update a user
- ❌ Delete a user
- 🧹 Delete all users
- 📥 Add multiple users (bulk)
