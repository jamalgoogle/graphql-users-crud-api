# GraphQL Users API

A simple GraphQL CRUD API for managing users, built with Node.js, Express, and Apollo Server.

> 🚀 Great for beginners learning GraphQL and Apollo Server with Node.js.

---

## 📦 Features

- 🔍 Query all users
- ➕ Add a user
- 📝 Update a user
- ❌ Delete a user
- 📥 Add multiple users (bulk)
- 🧹 Delete all users

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/graphql-users-api.git
cd graphql-users-api
```
### 2. Install dependences 
```bash
npm install
```
### 3. Launch the API (The Project)
```bash
npm start
```
